# Credits

MaxOCR's letters were built from fonts under the SIL Open Font License 1.1, then fitted, redrawn and tested.
DECISIONS.md records which font each letter came from. Letters taken directly in the current version include:

- Latin: n (Quattrocento), h (Enriqueta, with feet from MaxOCR's n), d (Arvo), s (Carlito), S (Literata), D (Manuale),
  G (Enriqueta), Y (Cardo), P (Mate), Q (Radley), I (Source Code Pro), T (Faustina), 1 (Aleo), 3 (Noto Sans),
  e (Spectral); earlier versions blended shapes from many of the fonts below.
- Hebrew: Arimo; ר ז ל ם from Cousine; ב י ד from Varela Round; ת from Secular One; ה from IBM Plex Sans Hebrew;
  צ from Frank Ruhl Libre.
- Cyrillic: Cousine; б ь from Noto Sans; й from IBM Plex Serif; the Latin look-alikes are MaxOCR's own letters.
